# Funngro Website Revamp — GitHub Pages

- `index.html`: Teenlancer landing page (homepage)
- `companies.html`: For Companies page
- `SEO_AUDIT.md`: SEO audit report

Both HTML pages are standalone and include their CSS and JavaScript.

After publishing, replace the `https://example.com/...` canonical URLs in both HTML pages with your actual GitHub Pages URLs. For a repository named `funngro-website`, the URLs will look like:
- `https://YOUR-USERNAME.github.io/funngro-website/`
- `https://YOUR-USERNAME.github.io/funngro-website/companies.html`

Update `robots.txt` and `sitemap.xml` with the same final URLs if you add them.
